# TeleShelf Pro

Official builds of TeleShelf Pro for Android TV will be published here.

TeleShelf turns the Telegram channels you follow into video shelves on your TV: what's
popular this week, the latest videos, continue watching, one row per channel.

**There is nothing to download yet.** The first public build appears here when TeleShelf
Pro launches. Follow [@teleshelf_pro](https://t.me/teleshelf_pro) to hear when it does.

## Only install the official file

Every official build is signed with this certificate (SHA-256):

```
4e5bc630c2a119d9ce22abe9f77a1191be749eac50af3ec4a306214a53fe768c
```

A file signed with any other certificate is not from us. TeleShelf logs in to your Telegram
account, so a modified copy would hold your whole Telegram session.
